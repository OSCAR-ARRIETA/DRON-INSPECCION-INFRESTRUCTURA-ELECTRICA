# 📖 Overview

This project presents the design and development of a smart drone capable of inspecting electrical infrastructure safely and efficiently.

The system integrates an ESP32-S3 thermal camera, GPS module and environmental sensors to collect real-time information while reducing risks for maintenance personnel.

---

# 🎯 Objectives

- Inspect electrical infrastructure remotely.
- Detect abnormal temperatures.
- Obtain GPS location.
- Monitor environmental conditions.
- Reduce inspection time and operational risks.

---
